# Bachelor Thesis
The thesis, titled “Extraction of kinetic parameters in a Chemical Vapor Deposition Reactor using methods of Scientific Machine Learning (PINNs)”, was carried out as part of my studies at the School of Chemical Engineering of the National Technical University of Athens.
This repository contains all the MATLAB codes that were used to produce the results presented in this work (used in Version R2025a). Additionally, the COMSOL files used to check the accuracy of the solutions and provide data for the Inverse Problems are included (Created in Version 6.4)
